# Security policy

VibeScroll maintains its latest alpha on a best-effort basis. Release checks and implemented protections do not establish an independent security audit or certify another operator's deployment.

## Report a vulnerability

Email [contact@exponentialeducation.ro](mailto:contact@exponentialeducation.ro) with the subject "VibeScroll security report". This is the existing private reporting contact in the application's acceptable-use policy and contact page. GitHub private vulnerability reporting was disabled for this repository when checked on October 22, 2026.

Include the affected version or commit, UTC time, a minimal synthetic reproduction, expected and observed behavior, and likely impact. Request a private exchange before sending sensitive evidence. Keep credentials, session cookies, signed URLs, customer identities and private media or code out of public issues and the initial email.

No bounty or response-time guarantee is published. This reporting policy does not authorize testing third-party services.
