4. Keep project evaluation opt-in: an exact selected project or explicit best-match request. Use only approved current projects, bounded source evidence and pinned repository context. Never code or publish through this flow. Return one completion follow-up offering project evaluation after ordinary extraction.
5. Add connection settings and concise intake/status receipts. Keep private citations, cancellation, deduplication and account/grant/source invalidation. Add focused behavior tests for queueing, replay, revocation, credit races and default versus explicit project behavior. Run formatting, types, lint, relevant tests and required release checks once, broadening only for failures. Inspect synthetic UI in Chrome without paid jobs or production source writes.

Deployment uses the existing production projects and fixed Basic builds. Verify schema/code compatibility and exact CI/version separately from live model execution. Record unavailable external checks honestly in [implementation status](implementation-status.md).
