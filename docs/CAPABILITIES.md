Metadata capture, completed analysis, accepted plan, draft PR, merge and measured benefit are different facts. Demo fixtures contain authored records; customer content stays private. Media/evidence follow published retention and deletion policies.

October 20 automatic assistant intake adds reviewed local extraction/organization defaults, offline waiting, optional explicit credit quotes with settled receipts and project evaluation only when requested. Local handler/runner tests and synthetic desktop/mobile UI checks are recorded in implementation status. Existing connections need one preference review and the local runner must be available; deployment and actual model execution are separately recorded. See [local assistant setup](operations/assistant-local-runner.md).

Assistant retrieval exposes approved extracted ideas and evidence timestamps, not original transcripts, media, repository code or chat history. Search examines up to five posts and returns up to 20 matching ideas per page; follow the returned cursor for more. New agent hosts require registered OAuth clients. Public plugin distribution, provider revocation acceptance and real host write-tool acceptance remain separate gates; MCP Events stays off. Connecting alone does not authorize processing. Separately reviewed local preferences permit own-plan intake, credits require their explicit quote approval, and coding/publication keep separate approvals.

| Symptom                           | Safe response                                                              |
| --------------------------------- | -------------------------------------------------------------------------- |
| Source unavailable                | Inspect status; permitted-media fallback rather than blind retries         |
| Budget exhausted or unknown usage | Preserve reservations; stop paid work and reconcile usage                  |
| Laptop offline                    | Resume the paired runner or explicitly select an available quoted route    |
| Disconnected provider             | Reconnect the intended account/repository; refresh context before approval |
| Unknown write/checkout result     | Read authoritative state before retrying; do not duplicate side effects    |
| Failed isolated checks            | Inspect failure; refine/export or authorize bounded repair                 |
| Foreign-workspace exposure        | Report privately; current membership is required for private objects       |

Support uses the published contact route. Include version, safe error code and time; omit token-bearing URLs, source text, keys and private code. [Security reporting](SECURITY.md) and [operator controls](operations/vibescroller-deployment.md) cover escalation. No staffed 24-hour support or recovery-time guarantee is established.
