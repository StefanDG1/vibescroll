# Automatic assistant link intake

Mode: reference. Decision October 20, 2026. Owner-authorized implementation; release and live-account activation require separate evidence.

An explicit link submitted to the selected VibeScroll assistant is a save request. Remove repeated per-link rights/confirmation fields from the tool's required inputs. A reviewed connection may authorize processing of future explicitly submitted permitted links. Store that standing permission's provenance; never invent a fresh per-link declaration. Existing grants do not silently acquire processing authority.

Configured automatic intake uses the user's paired computer and own ChatGPT allowance. Default output is cited extraction and organization. Offline work waits durably until the computer requests work, when a fresh finite local-library run is created. Use indexed queues, one active source per device and no recurring server-side readiness checks. Keep official-client credentials local and isolated; disabled personal-account eligibility stays disabled.

Offer an optional separately approved credit route with current unexpired credit balance and an exact maximum. Reserve atomically, bind the approval to the current source generation and quote, and never switch route after work starts or usage becomes uncertain. Distinguish ready output, failed processing, reserved or unreconciled cost and final actual usage. A later balance observation is current balance, not a fabricated historical settlement snapshot.

Project work requires an explicit exact project selection or a request to find the best matches among approved current projects. It produces private evaluations only. Default completion offers this next step without launching it. Coding, issue/PR publication, merge and deployment keep their existing approvals.

Affected contracts: assistant grants/intakes, MCP and HTTP schemas, local-library runner authorization, credit receipts and Connections UI. Tests cover default extraction, offline queue/claim, repeated saves, stale/revoked grants, foreign accounts, expired credit pools, competing local/credit claims, unsettled holds and optional project work. Public plugin distribution, persistent host Events and general hosted subscription usage remain separate gates.
