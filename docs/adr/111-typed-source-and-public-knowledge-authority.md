# ADR 111: typed source and public knowledge authority

Accepted October 22, 2026 for the implemented, unreleased candidate. Exact candidate commit: `ROOT_CANDIDATE_COMMIT_PENDING`. Root must replace this marker after integration; local fixture results do not establish exact-head CI, deployment or provider permission.

## Context

A GitHub repository, Reddit discussion and supplied text have different evidence from sampled video. Reusing a video timestamp contract would invent provenance. Saving a public edition also needs a continuing permission boundary rather than a permanent copy of another person's analysis. The October 22 work therefore adds typed evidence through retrieval, analysis, project decisions, assistant retrieval and explicit publication.

## Decision

Keep metadata capture, provider retrieval, analysis and publication as separate actions. GitHub retrieval inspects a public repository at a pinned commit, presents bounded regular text files for selection, and verifies selected blob identities before accepting the revision. Reddit retrieval requires current server-held workload and retention eligibility plus dedicated OAuth; fixture eligibility grants no real permission. Supplied text is a separate recovery path labelled supplied and provider-unverified. Source files, including README and AGENTS, remain untrusted data and cannot grant authority.

Accepted revisions have immutable content/evidence hashes, source identity, generation, rights and retention bounds. Typed v2 insight and proposal contracts bind the exact source revision and hash. File/commit/line, OP/comment/parent and supplied-offset citations keep their actual kinds; untimed evidence has null timestamps. Legacy media retains its existing contract. Typed missing-pointer or malformed evidence cannot downgrade into legacy authority. Canonical checks apply at reservation, reuse, result acceptance, assistant/team retrieval, project proposal and public publication boundaries.

Direct adapters remain release-gated. Requests have finite leases, deadlines, byte/request ceilings, persistent provider quotas and explicit retry. Rights renewal requires fresh attestation and exact source fences; it clears old provider evidence before enabling a new retrieval, never reauthorizing the old bytes or starting inference.

Publication requires exact reviewed payload/version/hash and explicit disclosure. Collection bindings include each edition's identity, version and hash. Anonymous routes use only allowlisted current public DTOs with slug and date-level publication metadata. The anonymous web release switch and backend publication/provider gates remain separate; disabling anonymous access must not strand authenticated withdrawal. Withdrawals, correction/version changes, rights loss, expiry and source removal deny stale public reuse immediately. Saved public sources retain an actor-private authored layer and a currently permitted public base; another workspace actor does not inherit private notes.

Discovery uses bounded list/topic views with an explicitly opened, static, lazy globe alternative. Broad geography requires voluntary opt-in and the current contributor threshold; counts describe a bounded snapshot, never exhaustive participation or precise location. No polling, geolocation or invented contributions are introduced. Saving an edition preserves its exact slug/version through authentication and workspace choice, then requires an explicit authenticated action; GET navigation never imports it.

Expiry and deletion scrub provider and generated evidence through bounded, generation-fenced continuations. Authored corrections/manual history and published PR/financial receipts have separate retention roles. Restore quarantines source/public dispatch authority and retains conservative provider quotas and unknown financial holds; old publication or acquisition cannot resume merely because a backup was restored.
