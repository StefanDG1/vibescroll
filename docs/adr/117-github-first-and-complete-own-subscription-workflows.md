# ADR 117: GitHub first and complete own-subscription workflows

Date: October 23, 2026. Status: owner decisions adopted; implementation and live acceptance pending.

## Context

The owner reviewed the seven real README insights, authorized their use, changed release order to GitHub first/Reddit later, and requested each eligible user's own subscription for video processing and selected-repository proposals/plans inside VibeScroll. Independent testing will happen later in production. Relevant VibeScroll and Exponential Education examples are permitted; unrelated private material remains excluded.

The audit found additional code gaps: joint provider currentness gates, publisher reversal of moderator removal, misleading supplied-text public provenance, conflicting workers, incomplete effort readiness, repeated preparation on retry, managed-only app planning, a first-pairing preflight loop and stale Help. The previous passing suite does not close newly identified gaps.

## Decisions

Release GitHub independently when its currentness, rights, quota, authentication and acceptance pass. Preserve master/restore/capture controls. Keep Reddit behind independent default-off activation, dedicated credentials, current workload permission and exact retention/deletion identity. This supersedes October 22's joint release condition without weakening Reddit prerequisites.

Build the complete source-to-selected-project evaluation/proposal/editable-plan path through the chosen user's own eligible runtime. Reuse current processors/editor under one protected controller and serialized worker. Bind actor/workspace/device/profile, source/repo/proposal versions, model/effort, funding, lease and deadline. Keep execution/publication separate. Never silently fall back to managed inference or pool the founder account.

Prepare scalable per-user/workload eligibility instead of a larger founder allowlist. Commercial/hosted activation stays closed until official permission covers its exact deployment/workload. A local companion does not establish commercial permission. Preserve authorized narrow local testing and credential isolation. Video uses permitted preparation and bounded text/images rather than unsupported raw audio/video inference.

The seven-claim human review is complete for that exact result. Final preview/hash, rights, expiry and reuse choice still govern publication. Fix durable moderator authority before public activation. A supplied README reference remains unverified supplied provenance, not direct acquisition. Images must be useful and permitted; private frames/project context are not automatically publishable.

The website needs no Windows signing certificate. Preserve genuine signature checks for maintained downloads/updates. Reviewed source execution is distinct from signed customer installation. Signing does not resolve local-coding isolation. No certificate purchase follows.

Independent testing is future evidence, not a reason to retain broken onboarding. Build eligible-user self-service preparation and precise unavailable states now. Preserve provider, quality, community, financial and operating acceptance requirements.

## Implementation and verification

Follow the [October 23 plan](../launch-plan/2026-10-23/README.md) and [ledger](../launch-plan/2026-10-23/ACCEPTANCE.md). Regressions cover independent GitHub currentness/Reddit denial, moderator re-publication, supplied provenance, tenant/task fencing, one controller, effort capability, no paid fallback, preparation reuse and fresh setup. Preserve compatible data and tested behavior.

No flag, live job, publication, paid service or release is activated by this ADR. Original cumulative spending remains capped at US$2 unless a separate concrete proposal is approved. The owner explicitly authorized the observed root Sol High for this continuation. Keep Ultra off. The paired-computer route is the immediate target; computer-free hosted use follows provider approval. Saving/reuse of the seven reviewed published insights is allowed, and the original US$2 cumulative cap remains unchanged.
