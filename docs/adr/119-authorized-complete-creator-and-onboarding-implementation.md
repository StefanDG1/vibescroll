# ADR 119: authorize the remaining creator and onboarding implementation

Date: October 23, 2026, Europe/Berlin.

Status: accepted implementation authorization; production and provider gates remain enforced.

## Decision

The owner explicitly authorized implementing N0-N7 and all remaining work from both launch plans. This supersedes ADR 118's planning-only boundary. Its architecture and privacy constraints remain: extend SetupJourney/CompanionSetup/librarySetup, existing durable processing jobs, source/evidence contracts and the public artifact/import family. Do not create parallel onboarding, inference queues or reusable-analysis stores. Root owns shared contracts, integration, cost accounting and final review.

Implement daily public TikTok/Instagram discovery, ordered image/video/carousel evidence, independently eligible generic reuse and private personalization, supported local own-subscription and approved cloud routes, future-only default and optional latest ten. Implement the confirmed project-builder chapters, optional GitHub/skill installation, explicit VibeScroll invocation with fallbacks, mandatory export education separate from later export/import, optional following and accessible Help/media.

Use reviewable feature stages with exact-head tests and CI. Preserve previously tested behavior, unrelated changes and source-only/local/mobile use. Provider contracts, actual account access, source rights, retention, privacy, isolation, signing, customer usefulness and production acceptance remain separate evidence. Implementation authorization cannot supply them.

## Spending and production

The original cumulative US$2 ceiling does not reset. The last conservative ledger retains US$1.6792885298898517, including the unchanged unknown holds, leaving US$0.32071147011014833 unallocated. No other new spending, supplier trial, billing change, paid fallback or unbounded monitoring is authorized. Use local/offline tests first. Reserve verified conservative combined costs before any hosted operation; otherwise leave live tests pending and continue independent implementation.

The owner's existing production/merge direction remains conditional on these gates. Do not merge application changes that cause an unfunded build, remove branch deployment suppression prematurely or enable unapproved providers. Fixed Basic builds, controlled exact-build promotion and honest rollback/evidence remain required. No new customer, generation, contributor or live success is invented.

## Contracts and acceptance

The [single remaining-work plan](../launch-plan/2026-10-23/README.md) and [ledger](../launch-plan/2026-10-23/ACCEPTANCE.md) retain every original and N0-N7 scenario. Existing reviewed publication/reuse of the seven README insights remains authorized. New automatic shared analysis needs its own origin, rights and payer contract. Individual subscriptions never become a shared service inference pool. The required Instagram guide is education, not consent to access an account, start processing or import an archive.
