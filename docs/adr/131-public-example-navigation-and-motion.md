# ADR 131: public example navigation and controlled motion

Status: accepted for local implementation; browser and production acceptance pending. Date: October 24, 2026.

Extend the existing public hero with a native example selector and five existing destinations. Keep the primary actions, headline, routes, approved media and pricing. Each option describes its evidence honestly: synthetic cited passage, synthetic project decisions, an earlier founder-result capture, a synthetic Library demo or Help. The selector opens existing content and starts no analysis, project task or spending. It has no free-text submission or model request.

Render an initial working anchor and all ordinary alternative links on the server. Put the alternatives in native details, with no-JavaScript guidance. Keep labels, text and navigation usable without JavaScript or animation.

Cycling is static by default. Explicit Play or Restart can cycle complete options every three seconds only on a desktop with a fine pointer/hover, enabled interface motion, a visible document and at least half the selector visible. Focus, keyboard interaction and selection pause until explicit Play. Hidden/offscreen states suspend the timer and start a fresh dwell on return, without catch-up. Mobile and reduced-motion states remain static. Clean up listeners, observers and timers; ignore late observer callbacks. Do not announce decorative rotation through a live region or represent it as job progress.

Use the existing motion preference and scoped `.public-site` styles. Preserve minimum control sizes, wrapping at narrow widths, native selector semantics and the primary static list. No new motion dependency, original media, provider permission or release activation follows.

This is a bounded M1/M6 navigation/motion slice. One-time reveals, readable scroll emphasis, remaining original product/library/social edits and actual mobile/browser/media acceptance remain open. The same US$3 cap and all earlier holds apply; no hosted request or new spending is needed for this implementation.
