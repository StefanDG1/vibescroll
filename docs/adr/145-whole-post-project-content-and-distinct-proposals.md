# ADR 145: whole-post project context and distinct proposals

Date: October 24, 2026. Status: authorized implementation candidate; production acceptance pending.

## Decision

The owner requested Apply for the analyzed post as a group, including its complete retained transcript and available image pixels, with independently useful proposals for each selected repository. **Include full transcript and images** starts on. Turning it off sends extracted insights and citations without raw transcript, caption or image input. This is an input-usage choice, not a promise of a particular bill or speed.

Extend existing project evaluations, subscription tasks, proposals and plans. Do not add a queue or analysis store. Each evaluation can produce one to five distinct proposals per repository. Combine coupled changes; do not manufacture five changes or cosmetic variations. No fit, already implemented, unsupported, deferred and insufficient context remain valid outcomes. Every proposal retains its own cited ideas, repository base, review and separately approved plan. Acceptance authorizes no execution or publication.

## Content authority

Resolve content on the server after source/task authorization. Bind the retained transcript, caption and image descriptors into approval and cache identity. Changing the toggle invalidates the quote. Preserve generation, revision, rights, retention and the private variant's reference namespace.

Images mean actual retained pixels, not hashes or descriptions. Access checks source, workspace, generation, state, expiry, retirement, size and object version/checksum. Recheck before storage reads and immediately before inference, after remote repository authorization, and validate on commit. Missing material produces a warning; never silently reacquire it or label it complete. Cloud observations whose pixels remain provider-local do not become app-held images.

The own-subscription ceiling remains 48 samples and 12 MB. Managed images require the already selected compatible route and its smaller broker envelope. Oversized input stops and offers the subscription route or the off setting. No route switch, paid fallback, repeated source processing or new spending authority follows.

## Compatibility and persistence

Legacy single-proposal calls retain their contract. Managed groups commit atomically through existing matching jobs and proposals. Invalid or duplicated changes are rejected. Each proposal passes source and inspected-repository evidence validation.

Own-subscription groups require negotiated version-four task support. Older workers cannot silently omit images or extra proposals. The existing evaluation keeps its first output for legacy readers and a bounded opportunity group. Stable proposal ordinals preserve replay identity in the same table. Privacy, export, recovery and currentness include the group. Image reads are scoped; reuse is ephemeral, with no new retained media cache.

## Evidence and release limits

Root's eleven focused checks pass for atomic groups, independent review, exact-mode reuse, invalid-evidence rollback, image version/byte validation and withdrawal before disclosure. Review found a managed disclosure race, corrected through dispatch-time checks and cleared on re-review. Initial synthetic group fixtures lacked an inspected manifest and failed; correcting the fixtures preserved the product validator. Integrated checks, native UI, exact-head CI and production acceptance remain separate.

Cloud Work video remains unproven end to end in production. A fresh task selected no repository and reported current enforced restricted networking. Python and FFmpeg are present; downloader/ASR preparation is incomplete. A bounded model HEAD failed with a process permission error despite inherited proxies and configured CA trust. Supported internet permission and verified prerequisites must precede source approval and its finite execution lease. Structured readiness reports are host observations, not provider-attested execution. Never disable TLS, bypass the proxy or relax isolation to label the test complete.

The same cumulative US$3 cap and provider/privacy/release gates remain. One real production source remains reserved for the owner's test. This decision claims no new video, customer, provider approval, deployment or measured benefit.
