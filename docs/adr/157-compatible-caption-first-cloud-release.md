# ADR 157: release the Cloud repair from the serving baseline

Date: October26, 2026. Status: compatible candidate, not yet published.

## Decision

Prepare the first Cloud milestone from the last verified serving commit675dea2. Do not deploy full main while its five populated-index additions remain held. The complete Home/navigation/downloader plan remains in [PR185](https://github.com/StefanDG1/vibescroll/pull/185).

This release ports the corrected Cloud transcript renderer, authenticated JPEG return, a separate immutable-result repair lease, progressive native metadata, the reviewed caption-first package and direct `/app/{org}/posts/{id}` pages. Existing Library routes remain compatible. A selected post uses five existing queries and loads related-post choices on demand. It preserves ordinary source, project, billing, privacy and deletion behavior.

Keep the serving paired-job validator unchanged. Widen only optional asset generation, native-preview fields, Cloud v3 and optional repair authority. Add no tables, indexes, components, crons or activation settings. Current source schemas do not admit main-only creator/private-reanalysis workflows; those remain outside this compatible release. New v3 jobs require v3 preparation and every prepared JPEG before completion. Retained v2 jobs retain their original preparation and policy.

The new recently added Home cards, region/globe retirement and navigation changes remain in the tested main candidate. This compatible release does not claim them deployed. Its purpose is to unblock the actual Reel and inline Cloud path without an unrelated migration.

## Acceptance and budget

The cumulative cap is EUR7 after the owner's explicit response. The single ledger reserves the USD2.40 combined live envelope with all earlier holds preserved. Fresh metadata must confirm complete schemas, no validation walks and no populated backfill before publication. Fixed Basic queued builds, exact staged/canonical verification and provider/privacy gates remain.

Local source, parser/downloader/decoder, authentication, schema, MCP, renderer and browser tests precede a draft release PR. Local fixtures are not production evidence. The actual Reel must retain its analysis/preparation/generation, match original source and JPEG bytes, show the correct retained transcript and images, and receive source-speech review. A separate fresh caption-path example still requires a suitable permitted link. The reserved TikTok remains unanalyzed. Do not revive an expired lease or use paid inference.
