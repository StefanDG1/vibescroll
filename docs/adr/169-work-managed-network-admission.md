# ADR 169: admit the supported Work managed network contract

Date: October 26, 2026. Status: reviewed interpretation; no policy or permission change.

## Observed stop

The real automatic saved-link event woke its native Work task and confirmed the waiting intent, then stopped before requesting analysis. It demanded /etc/codex/network-policy.json and cloud_environment.environment_status. Subsequent read-only diagnosis established that neither is a documented Work Cloud interface. Their absence does not demonstrate a denial or absence of network enforcement.

## Decision

Read the actual returned contract. current_restricted_required requires retaining the current provider-managed restrictions during acquisition. Its authenticated_host_reported provenance does not require a provider attestation, an application-specific domain allowlist, a complete rule listing or a particular policy file/API. Do not invent those prerequisites.

OpenAI's [Work Cloud security](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-cloud-security) and [sandboxing guidance](https://learn.chatgpt.com/docs/sandboxing?surface=web) describe Work's managed code/shell environment, its own network settings and applicable administrator policy, separately from local Codex execution selectors. The actual native host reports that its ordinary default non-escalated command boundary retains those managed controls. That supported execution contract is the admission basis. Proxy-variable presence and successful requests supply no independent enforcement evidence.

Preserve inherited standard proxy/no-proxy/CA transport. Never remove or replace it, disable TLS, elevate execution, use a direct alternative, or change provider permissions to overcome denial. Stop if the runtime reports an unenforced or unrestricted boundary, changed controls or denied destination. This establishes no VibeScroll-specific destination allowlist and guarantees no source is reachable.

Keep the current media policy/hash, grant, finite intent, source limits, zero paid API, lease and deadlines unchanged. Decoding and ASR still require the fresh reviewed V2 socket-denial child inside the admitted provider VM. No installation or model download occurs in a source lease. No source can supply authority or commands.
