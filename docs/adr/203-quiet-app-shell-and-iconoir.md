# ADR 203: quiet app shell and Iconoir

Date: October 30, 2026. Status: implemented and visually checked locally; publication pending.

The owner requests an uncluttered assistant-ui/Codex visual direction with suitable shadcn components and a different icon library. Follow [the design reference](../design/QUIET-APP-REDESIGN-2026-10-30.md), R102.

Reuse the current Radix/Tailwind/shadcn-style primitives. Introduce app-scoped neutral light/dark tokens, compact navigation and progressive disclosure for secondary home content. Add Iconoir's pinned MIT SVG subset with its licence rather than a new icon runtime dependency. Keep mobile navigation, source evidence, analysis controls, authentication and current funding/retention boundaries.

This is a presentation change, not the entire shared reader/proposal release. The existing ChatGPT widget remains disabled and direct hosted subscription inference remains paused. Local checks and rendered HTML are distinct from the required browser visual/interaction acceptance and a production release. Record those outcomes before calling the redesign live.
