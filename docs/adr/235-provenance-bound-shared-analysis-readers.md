# ADR235: Bind shared readers to actual execution and selected evidence

Status: implementing under R152, November2,2026.

A model identifier can name both subscription-host and API execution. Completed publication authority must choose its processing review using the stored provenance and actual configured provider, not the model name alone. A subscription result keeps its preparation review; a managed OpenAI API result still needs its independent API review.

Full-detail reads resolve the selected immutable analysis and its validated retained evidence before the legacy ordered-media fallback. Once a post has an authorized shared version, an old private preparation is neither its evidence nor an alternative after withdrawal. Preserve current source rights, membership, grant, Pro, catalog policy, version/evidence hashes and frame checks.

No record migration, new schema/index, operating-policy change, provider request, media acquisition or model call is needed. Existing saved results remain unchanged. Regression coverage includes model-name collisions, summary/exact-version/full-context/image retrieval and explicit denial after preparation permission change or artifact withdrawal.
