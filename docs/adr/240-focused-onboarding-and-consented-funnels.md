# Focus the onboarding steps and measure where people leave

19 November 2026.

Keep the four-question quiz and answer recap. Give the real curated example and personal link entry their own screens. The landing page can also open the existing authorized curated preview directly. It uses the same one-preview limit and needs neither authentication nor fresh analysis. The signed preview cookie keeps the same item when someone returns or changes interests.

Explain account creation after the example or link choice. Preserve the existing signed draft and WorkOS handoff. Keep Instagram import in the app, with existing in-progress import sessions still resumable. Let new users go to Pro plans from the optional assistant step. On the paid own-link branch, make saving the staged link the primary action and open the saved post using the existing credit quote and processing controls.

Revision 2 of optional analytics asks for consent before storing a random identifier in the current tab. A signed-in evidence or plan activity can retain that identifier in the browser for up to seven days. It contains no account or workspace identifier. Clear the optional storage on withdrawal and sign-out. Do not add recording, automatic capture, raw URLs, pitch or answer texts, or payments from client signals. The PostHog funnel reports opted-in browser observations. Verified Stripe and entitlement records remain the source for paid orders, refunds and revenue.
