# Recover legacy shared post authors

26 November 2026.

The first global creator index found stable account IDs in two of 92 retained shared results. Older video evidence preserves transcripts and screenshots but does not contain a complete post manifest. This prevents those results from appearing under their verified author.

Read public identity metadata from the exact original post. Instagram's captioned embed exposes the owner ID, handle and post permalink for public videos as well as images. TikTok's structured post page exposes the exact post and author IDs. For legacy TikTok short links, follow at most four manually checked TikTok redirects to a direct post. Refuse foreign destinations, loops, private items, ambiguous authors and identity changes. X post metadata uses the existing public FxTwitter service. This does not supply an X creator timeline.

Retain a compact, validated identity proof on the creator catalog row. The proof binds the post key, stable creator ID, handle, observation time and adapter. Short-link proofs also bind the input and resolved URL. This adds one optional field without changing existing indexes. A fresh publication review must accept the actual schema prediction before deployment.

Revalidate the selected independently owned artifact before indexing and before returning legacy creator metadata. Continue to require full-catalog access for global browsing. Blocked or withdrawn artifacts cannot restore access through the creator index. Never fabricate a complete media manifest or content fingerprint for an older result.

Repair existing source metadata only through valid current shared-import associations. Page eight associations at a time through the artifact index. Confirm source, workspace, generation, retention, rights, selected analysis and canonical post bindings. Preserve analysis versions, selection, revision, timestamps, private overlays, screenshots and all credit holds. Future cache saves receive the same verified identity. An unverifiable legacy post remains available under its existing rights and stays unattributed.

Metadata reads use no model or media preparation. The release migration has a separate reviewed bound of 128 families and preserves inaccessible results. New shared video publication schedules the same identity recovery when its retained manifest lacks an author. A successful retained proof makes the operation idempotent.

Focused tests cover public metadata parsing, malicious redirects, stale and mismatched proofs, retained-result preservation, creator-page access, Follow and withdrawal. Local probes recovered three legacy Instagram authors and the stable author behind a numeric TikTok URL. Production recovery and coverage must be recorded after deployment.
