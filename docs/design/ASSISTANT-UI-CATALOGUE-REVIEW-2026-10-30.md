## Important contract findings

- RecommendationCard confidence bars are a fixed decorative shape; their text is supplied by the caller. Use the real versioned score and criteria instead. The standalone card does not implement proposal persistence/publication.
- ArtifactCard is a controlled document summary; its button-like appearance does not create a keyboard button or action by itself. Add actual semantic navigation/action and truthful persistence status.
- Standalone ChatPanelComposer renders placeholder presentation and calls onSend; it is not a complete text editor. Use a real controlled textarea and durable message transport. assistant-ui cloud is not required.
- FeedbackDialog owns no open state and calls onSubmit using caller-controlled values. Mount it inline/on demand and persist feedback ourselves. Editing a sent message can discard later replies in a chat runtime; it is not our versioned plan-edit operation.
- ApprovalCard UI is not a permission system or GitHub client. Bind the single approval/write action to the exact current proposal, project and frozen issue package outside the model.
- JobProgress needs real weights/progress; keep observed steps until measured. StreamingText/word counters/tickers must follow actual server data and respect reduced motion.
- Chart clamps a visible series to at least one point, so handle no-data before rendering. NumberTicker guide examples fall back to zero while loading; our loading/unknown state must stay distinct from a real zero.
- CostMeter formats caller-provided amounts/shares. It does not calculate costs, settle credits or validate all shares. Preserve fixed-point accounting and unknown holds in VibeScroll.
- MediaPlayer wraps actual media URLs; it does not solve Instagram/TikTok acquisition, embed access or autoplay restrictions. Retained screenshots remain useful when a player is unavailable.
- Standalone chart/data-table/number-ticker source uses React and local utilities, not an unavoidable new chart service or Recharts dependency. ImageGallery/TooltipIconButton need their dialog/tooltip/button primitives. Inspect each selected dependency rather than installing the private upstream UI workspace with its entire dependency graph.
- The inspected source is MIT with the retained AgentbaseAI notice. Copied components need their own pinned notice and alias/theme adapters. No component choice creates provider, billing or runtime authority.
