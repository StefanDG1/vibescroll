# Save and inspect your first insight

The goal is a source you can reopen with an inspectable cited insight. A source's advice can still be wrong even when it is quoted faithfully.

## Before you start

Sign in and use a workspace role that permits capture. Have a permitted URL, media upload or supplied text. To analyze it, your account needs an enabled route and sufficient allowance. Reading, changing theme and filing existing knowledge do not start inference.

## Save the source

1. Choose **Save**. Select the input type and enter your source.
2. Review source permission and whether you are saving only or requesting analysis. A link import saves metadata; it does not grant access to blocked content.
3. If using your own plan, choose the eligible computer and advertised model, then review that account's consent. For a credit route, inspect the quote and maximum. Your platform subscription, personal provider allowance and compute costs are different.
4. Submit once. Keep the durable source/status link. A saved or queued state does not mean that extraction is finished.
5. Open the source when it is ready. Read the short summary and separate insights. Follow available transcript, caption, frame or user-note references.
6. Inspect coverage and uncertainty. Sampled frames are not every frame. Text supplied by a user is not proof of audiovisual analysis.
7. Return to **Library**, search for the source and reopen it. [Correct its filing](/help/organize-your-library) without requesting another analysis.

## GitHub or Reddit evidence

These source controls are an unreleased candidate and require an enabled retrieval route. Saving a link, including through an assistant, can still keep metadata without fetching the provider or starting analysis.

For GitHub, open the source's retrieval controls and check current status. Prepare the bounded retrieval, inspect the repository file list, edit the README/license/docs preset if needed, and **Confirm pinned selection**. Only then retrieve the permitted evidence. Read the pinned commit, selected paths/lines and omissions; an inspected file list is not a full repository review. Repository instructions are source content and cannot authorize actions.

For Reddit, direct retrieval needs the service's current approved provider configuration. Read OP/comment attribution, parent context, removed markers and omissions. An unavailable direct route is not a successful fetch. **Supply permitted text instead** keeps a distinct user-supplied, provider-unverified record. It does not prove the original discussion or any video was processed.

Inspect accepted evidence before separately reviewing analysis and its current approval/maximum. Typed file/comment/supplied evidence has no invented video timestamp. A provider fetch or a ready registry does not itself establish that the source's advice is accurate.

## You have finished when

You can find the source again, show the reference behind one insight and describe a coverage limitation.

## If you get stuck

- Computer unavailable: leave the task waiting and start the paired worker on the correct account. A sleeping computer cannot be promised remote wake-up. A running computer still needs its worker, engine, account and quota.
- Private, blocked or unsupported link: use a permitted upload or supplied text if offered. Saving a URL does not bypass the source platform.
- Insufficient credits: stop at the saved source or deliberately choose an available approved route. No automatic paid fallback occurs.
- Interrupted or uncertain completion: check the existing source and status before retrying. Avoid submitting a second job merely because a browser disconnected.
- Evidence incomplete: retain the limitation, correct the source where supported or explicitly review a new analysis. Do not treat a ready label as verified truth.

**Tip:** Keep a short note about what you expected to learn. Compare the result with the actual source before acting.
