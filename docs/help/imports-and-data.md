# Import saved links and manage your data

A saved-link export is an inventory. It does not contain permission to retrieve every source or a completed analysis.

## Before you start

Use an export you are allowed to process and a role that permits import. Keep the archive private. Start with a small preview before requesting any batch processing.

## Import deliberately

1. Choose **Save** and the available import option.
2. Select the supported saved-link export. Review the local preview, source count, duplicates and unsupported entries.
3. Choose whether to save metadata only or analyze through an enabled route. Batch processing needs explicit scope and a reviewed maximum.
4. Submit the reviewed batch. Keep its accepted, duplicate and waiting results separate.
5. Open a saved entry. A blocked or private source may require a permitted upload or supplied text. Do not assume imported means analyzed.

## Export and deletion

Open **Account**, then **Privacy**, for the currently available export and deletion controls. Review scope before confirming removal. Exports contain private information and belong in protected storage.

Deleting a VibeScroll source does not erase previously disclosed material from a recipient or rewrite GitHub history. Connected grants, derived records and public editions have their own currentness/removal behavior. Public publishing remains subject to its availability gates.

Expired or revoked provider evidence becomes unavailable even before background cleanup finishes. A fresh retrieval needs current permission; restoring a backup does not resume old processing or publication authority. Your own retained notes/corrections are distinct from provider excerpts and generated material. An exported saved-public-source record includes your own private layer, not a permanent copy or renewed permission to the public base.

## You have finished when

You can distinguish accepted links, duplicates, waiting work and ready analyses, and know where to export or remove your records.

## If you get stuck

Keep the preview when repairing an expired sign-in. Check the supported archive format and file limits. Do not repeatedly upload a large archive to work around a quota. If an import's completion is uncertain, inspect the saved records before submitting again.

**Tip:** Save metadata first when you are unsure about a batch's processing cost.
