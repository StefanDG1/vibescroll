# Find and organize your library

The goal is to reopen the right evidence and place it where you will look next time.

## Before you start

Have at least one saved source. A ready analysis supplies insights; a metadata-only save can still be waiting for extraction. Reading requires current workspace access. Editing requires a suitable role.

## Find and file

1. Open **Library**. Use search and the available filters. Clear filters if a source seems to have disappeared.
2. Browse **Tree** or **Folders**. Both present the permitted knowledge in your current view. A branch's loaded count is not a whole-library total.
3. Open an insight or source and inspect the cited evidence. Follow the source reference rather than relying on a short card title.
4. Use the available filing and topic controls to correct organization. Keep your authored correction when reviewing a later AI suggestion.
5. Use **Library options** for topic organization, pins and exclusions where your role permits them. Personal/Business filing changes organization; it does not grant team or assistant access.
6. Return to the previous branch or search and reopen the evidence. Navigation can remember a valid position. If records or permissions changed, use the current available view.

## You have finished when

You can find the same source through search or its branch, explain where it belongs and reopen the underlying evidence.

## If you get stuck

- Empty Library: first check whether this is the right workspace, view and filter. An empty search is different from an empty library.
- Missing shared result: check current access. Revocation, expiry or a source correction can invalidate an old reference.
- Duplicate link: inspect the existing source before requesting new processing. Import previews show duplicate handling.
- Confusing parent counts: related branches can overlap. Counts do not establish that each insight produced a unique project change.
- Filing seems wrong: correct the organization where supported. Theme changes, navigation and filing do not require paid reanalysis.

**Tip:** Use a small set of labels you would actually search for. Personal interests and project knowledge can stay separate.
