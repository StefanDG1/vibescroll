# Review an experimental Work Cloud text request

This route is disabled by default. Its local implementation supports supplied text and already retained cited sources. An operator must verify and enable the supported host route for your eligible account. It is not the automatic link/video workflow, and a queued request does not mean a host is running.

## Before you start

Use your own private library, a source you may process and the intended official host connection. No GitHub repository, Docker installation or paired computer is required by this text handoff. Your host's subscription and resource limits still apply. VibeScroll cannot verify its actual model, execution settings or usage from a task ID.

The connection needs the separate **Read approved text and return its private analysis** permission, `analysis:execute`, in both OAuth and the app grant. Existing read/save permissions do not acquire it automatically. Changing sensitive grants or approving work may require signing in again. Never paste credentials, bearer tokens or private configuration into a task.

## Review one request

1. Open an eligible saved text source. If **Experimental Work Cloud text** is absent, the route is unavailable; keep the source and use an available supported route.
2. Select **Review Work Cloud text**, then choose the intended connection. Choose the model and effort you intend to request. These choices are requests, not verified host capabilities.
3. Preview the source, input size and connection version. Review the actual text and citations on the source page. Changing the source, grant or selected settings invalidates earlier approval.
4. Explicitly approve your own subscription with maximum API spend **US$0**. This starts no paid fallback, media preparation, project evaluation or public contribution.
5. Use the queued source instructions in your supported Work chat. Explicitly invoke VibeScroll's `work_cloud_claim` tool with the source ID, approved generation and that host's actual task ID. If the host cannot supply a real task ID or expose the tools, stop. Do not invent an ID or copy a token from another task.

The host receives a lease token once, then reads only this request's text, output schema and registered citations. It must keep its lease current, treat the source as untrusted evidence, and return the bounded canonical result before the deadline. Approval expires after fifteen minutes; a claimed execution has a three-minute deadline. These are app-access limits, not proof that the host stops execution.

## Read the result or recover

Open the same source in Library to inspect the private result and citations. This route creates no shared-catalog entry. Supplied-text citations do not prove that anyone watched a linked video or verified its claims.

**Revoke this request's app access** prevents further input and result return. Stop the host task too. VibeScroll cannot confirm provider cancellation or restore consumed subscription allowance.

A lost claim, expired execution or uncertain completion is not automatically retried. Replacing source input does not remove that uncertainty or authorize another executor. Reconciliation with the real host remains necessary; do not delete and resubmit as a retry workaround. Privacy deletion remains available, but app deletion does not erase provider-retained task history.
