| Temporary failure or interrupted result | Completion or settlement may need reconciliation               | Inspect current source/run/receipt before another attempt. Do not repeat committed side effects.       |
| Deployment blocked                      | Required provider permission or isolation is missing           | Keep dispatch disabled. Use a separately eligible route or export the plan.                            |

## Evidence and spending limits

The new companion prerequisite report is local-only and redacted. It checks runtime/configuration metadata, Docker Linux-engine availability, cached pinned images, local transcription paths, saved-login-file presence and disk headroom. It neither opens credential bytes nor verifies server grants, account quota, model access or a cited sample. Its opt-in startup/pause controls are not a signed installer or a physical startup acceptance result.

The coordinated run has one shared US$2 additional Convex ceiling. This slice has a US$0 hosted reservation. Synthetic tests use `scripts/run-offline.mjs`, keep `VIBE_STAGING_TEST` unset and make no provider calls. Existing `.env` files, current-user Docker workers, grants and payment settings are untouched. New integration results belong in the root-owned implementation record with exact commands, environment, commit and limitations.

Rollback disables the affected new dispatch, preserves completed private artifacts and registrations, fences stale work and reconciles unknown holds. It never silently reroutes funding. Commercial provider approval, Windows/SIWC coding isolation, independent devices, current actual inference/revocation and complete human usefulness remain separate gates.
