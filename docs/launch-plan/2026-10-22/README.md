## The core experience

1. A visitor sees the actual Library style and an approved example without an account. The example connects a source, citations and a project decision. Label synthetic content and compressed waiting time.
2. After sign-in, ask what the person hopes to do with saved material. Offer library-first and active-project paths. Keep the purpose editable.
3. Explain only the permissions needed now. Connect an eligible route or show a precise repair. GitHub and bulk import remain optional before first value.
4. An explicit saved link promptly receives a durable status. Automatic extraction uses a previously reviewed grant. Save-only remains available.
5. The result shows a short summary, distinct insights, evidence references, coverage and uncertainty. Users can correct and file it without re-running inference.
6. Optional project review shows current context, relevance, evidence and alternatives. Keep no-fit, already-implemented, deferred and insufficient-context outcomes.
7. Retain an editable private plan and export. Coding, spending, final patch approval and draft PR publication retain their existing separate boundaries.
8. Returning Home presents the last useful result, a waiting item or unfinished decision. Preserve Library search, Tree/Folders and remembered navigation. Start with a compact return area; do not add an unrelated engagement dashboard.

## Public collections, reuse and the globe

Build personal usefulness before depending on a network. Create explicit public editions with provenance, a useful no-signup reading experience, save-to-my-library, reporting, corrections and removal. Seed a small permitted founder-curated collection and support creator-partnered collections later. Publication authority is distinct from private/team sharing.

Separate reusable source-level extraction from private notes, goals, project context and decisions. Reuse needs compatible content revision, language, pipeline/schema and coverage, plus a verified permission basis. A URL alone is not a cache key. Preserve corrections, deletion propagation and stale-artifact invalidation. Private activity must not leak through cache existence or timing.

Prefer eligible derived-artifact reuse over permanent video hosting. Raw-media acquisition, caching and redistribution require separate rights/provider evidence. Unsupported retrieval stays visibly unavailable rather than bypassing access controls.

The globe uses voluntary coarse sharing locations, aggregate thresholds and no inferred device/IP location. Provide topic/list alternatives, withdrawal, reduced motion and lazy rendering. Build and test the module with labelled fixtures; enable real public discovery only when the necessary contributions and controls exist. Do not present fixture activity as customer traction.
