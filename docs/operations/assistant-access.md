## Tool limits and recovery

Neither tool returns original transcripts, media, signed assets, credentials or chat history. An incomplete result page does not establish absence or no-fit.

Explicit intake reuses safe source URLs, rights, quotas and deduplication. It suppresses link previews, downloads and model work. Newly saved links are retrievable only when currently eligible for the chosen live scope; legacy grants still require separate exact-post review. Intake receipts cannot widen a live Personal or Business scope. Analysis requests without a mode return the existing app review link. Explicit local/project modes queue work under reviewed preferences; credits mode requires the user's separate current quote approval. Saving a link never silently chooses credits.

The adapter limits requests to 30 per actor/client per rate window. Request bodies and provider responses have byte limits and timeouts. Authentication failure requires official reconnection; app authorization failure requires review of the current grant/evidence. A temporary dispatch/configuration failure returns unavailable instead of an authentication challenge. Retry conservatively with the original intake key after an uncertain response. Never retry by widening scopes or selecting a paid provider.
