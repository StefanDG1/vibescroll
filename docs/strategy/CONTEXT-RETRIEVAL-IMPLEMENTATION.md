## Usage and ownership sketch

`fetch({id: sourceOrVersionReference, format: "post_context_v1", cursor?, sharedGrantId?, sharedGrantVersion?})` returns bounded retained context. `read_post_frame` reads one manifest frame with exact version/evidence identity and current authority. Neither creates a job, worker acknowledgment or credit operation.

Existing legacy and structured fetch behavior remain compatible. Contracts belong in the existing knowledge domain and a focused post-context module. Convex queries resolve current access and immutable version/evidence. The Node action verifies JPEG size, dimensions and hash, then rechecks authority after storage I/O. MCP presents actual native image content without base64 in model-readable text. Evidence citations keep their original observation identity and refer to shared frame/segment identities.

Workspace search uses a compact indexed candidate projection, not per-member media copies. Current source and exact team-share authority remain authoritative. Missing projections need bounded explicit coverage/recovery rather than a populated migration hidden in publication. New indexes/tables must admit empty state without historical scans/backfills, and existing results continue to work.

## Alternatives and synthesis

Extending current topic/member indexes alone avoids a table but cannot rank general claims: topic text is category-specific and member titles duplicate across topics without selected-version identity. A separate retrieval service adds deployment/auth synchronization before measured scale needs it. Choose current Convex ownership plus a compact workspace projection, reusing canonical immutable version/evidence references. Benchmark logical bounds and billed index behavior separately.

Acceptance distinguishes implementation, isolated tests, actual host discovery, production reads and measured cost. No broad semantic recall, installed skills or paid-user transaction is inferred from unit tests.
