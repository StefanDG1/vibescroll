This register does not grant new spending, source rights or provider capabilities.

Read [current state](../operations/CURRENT-STATE.md) for the latest accepted checkpoint and [continuation](../operations/CONTINUE-VIBESCROLL.md) for the next work. Older ADRs and handovers preserve what was known then. A historical present-tense statement is not current production evidence.

Status vocabulary:

- **Live**: the stated bounded behavior has a production receipt. It does not establish universal customer readiness.
- **Partial**: code or bounded acceptance exists, but the complete request remains open.
- **Open**: retained requirement or unanswered part of a question.
- **Deferred**: the owner explicitly removed the work from the current critical path.
- **Rule**: an active operating instruction, not a shipped feature.
- **Superseded**: a later owner instruction replaces the earlier choice.
