## Personal saves and catalog browsing

Retain permitted neutral evidence and immutable insight versions under an independent service owner. A personal library contains only posts the user explicitly saved or requested. Requesting an already-analyzed post creates that user's durable association and reuses the compatible selected version. It must not copy the corpus, duplicate media bundles, start inference or debit analysis credits. Browsing alone creates no personal association.

Base Pro includes compatible cache reuse for requested posts. Full-library browsing is a separate paid add-on with an account Settings toggle. The owner requests an enabled admin concession for their account. Record it as an operator grant, not a fabricated paid subscription. Paid add-on checkout and webhook activation require real commerce integration before purchase is advertised. Turning browsing off preserves personal saves and base cache reuse.

Full-library reads require current membership, entitlement and the enabled toggle. Return bounded metadata pages first. Fetch analysis and exact image bytes on demand, rechecking entitlement at byte disclosure. Cache compatibility includes content revision, language, evidence recipe, analysis/model policy and current source availability. Preserve distinct versions, selection and rollback. Equivalent concurrent requests coalesce while every Save remains durable. Unknown work retains its hold until reconciled. Takedown still blocks underlying content.

## Teams and individual subscriptions

Each member has their own Pro subscription and uses their own credits. The owner does not sponsor invited members. One account allowance spans its workspaces; team creation never mints another pool. New teams use a versioned individual-Pro policy. Invitation acceptance and subsequent protected access recheck the member's own subscription. Preserve legacy organization contracts until explicitly migrated.

Analyze in the member's personal account, then share selected retained insights through the existing team knowledge-sharing mechanism. Never spend an organization wallet to simulate individual funding. Membership and sharing do not start model work. Private notes and project context remain scoped to their actual sharing grant. Communities, likes, public discovery and moderation are later work.

## Preparation and precise settlement

Acquire permitted media once with yt-dlp/FFmpeg in the approved Sandbox route. Prefer native captions; otherwise run bounded API transcription. Retain actual images and transcript independently of the analyzer. Both Muse/API and a customer's supported subscription host consume versioned evidence. Never pool the founder's subscription or silently switch funding.

Preparation may consume disclosed infrastructure credits. Quote preparation and analysis separately, bound to route, model, reasoning, duration, recipes and tariff version. Keep intermediate cost/quantity arithmetic precise. Accumulate integer microcredits or another explicit fixed-point unit, then apply the final documented rounding rule once. A disclosed started-minute duration tariff is distinct from rounding intermediate money. Never sum independently rounded provider components as an exact total.

Reserve atomically and settle once against the exact reservation. Replays never spend twice. Release only known unused amounts; preserve unknown outcomes and old purchased-credit liabilities. A compatible cache hit has no new processing charge. Reanalysis charges only applicable new work. New units must not reinterpret old balances without a reviewed migration.
