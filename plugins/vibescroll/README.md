# VibeScroll plugin source candidate

This portable package points to the canonical Streamable HTTP MCP server and includes nine optional workflow skills. It has not been uploaded, installed into a host account or approved for the public directory by this source change.

- Setup: supported connection, human OAuth and workspace readiness.
- Save: stable receipts and the current exact-source Work Cloud flow.
- Find: bounded search and current cited fetch.
- Library: current knowledge navigation with no invented coverage.
- Compare: deliberately selected evidence, agreement and uncertainty.
- Feedback: all five judgments and versioned corrections.
- Project review: selected context, exact evaluations and private proposals.
- Work review: current work, existing protected plans/runs/PRs and approval boundaries.
- Status: actual current state and safe uncertain-result recovery.

Import this directory with supported plugin tooling after the matching widget backend/frontend are enabled and tested. Use official OAuth and preserve an existing app identity. A raw MCP connection still works without these skills. The source manifest intentionally contains no invented account binding, reviewer credentials, approval attestations or submission result.

The local implementation and remaining release conditions are recorded in `docs/widget/implementation.md` and `docs/operations/mcp-widget.md` at the repository root.
