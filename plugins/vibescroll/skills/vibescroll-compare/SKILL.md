# Compare current evidence

1. Identify the two to five selected ideas/sources. Fetch their current permitted evidence; do not infer access from copied IDs or an old export.
2. Explain where the sources agree, complement one another, disagree, or lack evidence. Cite each material claim.
3. Keep source claims separate from your new interpretation. Do not silently store a host-generated explanation as canonical app evidence or project evaluation.
4. Use the widget selection/compare view for side-by-side inspection when available. Attach only deliberately selected bounded context to the model.

The comparison starts no additional media processing, project evaluation, spending, publication or code execution. Saving a synthesis requires a supported separately authorized app workflow.
